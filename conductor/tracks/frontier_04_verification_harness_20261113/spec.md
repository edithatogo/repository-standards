## Requirement and contract
Convert verification-receipt contracts into executed, compared and enforced harness gates. Build profile-specific qualification rather than imposing expensive numerical/security tools on docs-only projects. Integrate scientific/native ownership; preserve consumer numerical acceptance and independent scientific validity.

For each canary profile the same revision yields valid repeatable receipts; mutated/failing fixtures fail; resource/cost budgets are bounded; scientific correctness is not inferred from green infrastructure tests.
