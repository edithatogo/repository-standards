# Approved specification

User approved implementation on 29 October 2026. Align Kairos, Voiage, Innovate
and MARS as independently released Rust-native scientific libraries. CareOps Sim,
tobac and VOP are first-wave consumers. Assess Lifecourse, Revalue and the
reimbursement game now; defer their migrations until first contracts pass.

Kairos owns deterministic simulation; Innovate owns adoption/diffusion modelling;
Voiage owns VOI; MARS owns splines. Applications own adapters and domain context.
Repository standards owns engineering policy, never a common numerical runtime.
Require acyclic capability ownership, minimal cores, explicit optional backends,
qualified current Python 3.15 and Rust toolchains, honest MSRV declarations,
frontier-first pinned candidates, bounded exceptions and producer-first migration.

Preserve numerical semantics, units, weights, missingness, deterministic replay,
buffer ownership and accepted fixtures. Require installed-consumer tests outside
source trees. Version breaking changes and provide migration instructions.
Keep runtime build, compiler source bootstrap, HPC package install and scheduler
proof separate. Voiage's HPC track remains required unless explicitly revised.
Every compiler bootstrap must trace to an approved packaging requirement.

Acceptance: executable ownership and candidate/receipt controls; source-bound
inventory; all four libraries modernised and their required gates passed;
CareOps/tobac/VOP installed acceptance; measured builds; agent correctness and
security review, fixes, current CI and integration in each repository.
A policy declaration or planned fixture is never runtime acceptance.
